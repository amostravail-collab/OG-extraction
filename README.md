# 老炮助手

把餐饮老炮脑子里已有的碎片经验，通过一问一答引导出来，按固定格式结构化、可视化，沉淀成可持续积累的经验库。

## 解决什么

讲过一次的事，团队凭印象做就跑偏。这个技能把那件事变成四样东西：一份九个字段的存档、一条简短结论、一张判断结构图、一份可勾选清单。

助手按设计的逻辑直接给归纳结论或真原因，不把素材拆成候选交使用者自己判。结论不保证正确，允许本人当场不同意；不同意的说法记下来，结论留痕标「有异议」，不删不覆盖。

## 三种用法

不确定从哪开始时，助手只问一题，选完不再问第二次。选项都是大白话，照着选就行。

| 你的情况 | 用途 | 本轮产出 |
|---|---|---|
| 有件事你自己也拿不准，想捋清楚 | 本人复盘提高 | 一问一答聊透 → 存档＋简短结论＋图 |
| 有件事你做成了，想让团队也学会 | 团队不会干，要经验指导 | 助手直接归纳 → 存档＋简短结论＋图 |
| 有件事你讲了好几遍、团队还是做不好，想要一份能照着干的清单 | 讲过一次的事成文，团队照着做 | 存档＋清单 |

说不清选哪个也行，就把最近反复强调的一件事说出来，助手帮你定。

## 直接说事

已经知道要办什么，直接说，助手跳过开场。

| 你说 | 得到什么 |
|---|---|
| 把上次那条判断出张图 | 判断结构图：情境 → 判断 → 原则 → 适用边界，一屏看完 |
| 给团队一份能对着做的 | 四段清单，每条标来源字段；适用边界没定下来时不出清单 |
| 那条判断后来结果出来了 | 原存档末尾追加一条回填，对照结论记命中与否，九个字段不改 |
| 看看我都存了哪些 | 按标签、验证状态、待补项数量筛选的盘点，只列字段 |
| 把上次没补完的打开 | 那份存档的待补项与情境完整性 |

## 你会拿到

- **一份结构化存档**：九个固定字段，答不上的地方留白、标「情境不完整」、列待补项，不替你补数字、不润色原话。
- **一条简短结论**：标「助手归纳」、带依据强度、挂原话位置。单轮产出不超过 200 字。
- **一张图、一份清单**：都从同一份存档转写，内容一致。
- **结果回填**：后来有结果，在原存档末尾追加，不覆盖原有内容。

## 数据边界

- 存档、图、清单都在你自己账号下的云工作区，不经过我们的服务器。
- 输入的一段感受、总结，或图片、文稿、录音稿，只作本轮输入；不落盘、不建材料库、不跨轮保留。
- 不追问信息来源，不恢复上次对话上下文，不续接未答完的进度。

## 安装

复制下面一整段，粘贴到自己的 AI 助手对话框发送：

> 从 `https://github.com/amostravail-collab/OG-extraction.git` 安装「老炮助手」技能。在我的用户级技能目录（WorkBuddy 为 `~/.workbuddy/skills/`）下建 `laopao-assistant/`，把仓库根目录的 `SKILL.md`、`references/`、`templates/`、`scripts/` 写进去，共 6 个文件；`README.md`、`LICENSE`、`UPDATE.json` 不要写进技能目录。装完回报写入了几个文件、引用路径是否可读。不要改动我的「经验萃取存档」目录。

安装由助手完成，不用点链接、下载压缩包或敲命令。仓库更新后重发同一段即可覆盖重装，`经验萃取存档/` 不受影响。

## 版本与更新

技能会在你每次使用时自动检查有没有新版本。有更新时，助手会在那次回答的末尾提醒你一句；你回复「1」，助手就自动覆盖安装新版，新建一次对话后生效。你的存档不受影响。网络不通或首次检查的 24 小时内不会提醒，属正常，不影响使用。

版本号按改动大小排：改句表述是 `1.0.x`，加入新场景或方法是 `1.x.0`，内核级迭代是 `x.0.0`。每次更新改了什么，记在仓库的 `UPDATE.json`。

`SKILL.md` 是入口，规则真源是 `references/经验萃取内核-版本9.md`，模板在 `templates/`，检查脚本在 `scripts/`。四处相对引用须保持同一目录层级。
